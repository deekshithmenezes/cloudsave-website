CLOUDSAVE AI SOLUTIONS - WEBSITE STARTER
=========================================

This is a custom, responsive one-page website for CloudSave AI Solutions Private Limited.

FILES
- index.html: website content
- styles.css: design and responsive layout
- script.js: mobile menu and demo enquiry form behaviour

IMPORTANT BEFORE GOING LIVE
1. Confirm that your company is authorized to describe itself as a Microsoft CSP / Microsoft partner. This starter uses general Microsoft cloud services positioning and does not claim a specific Microsoft partner designation, certification, tier, or authorization.
2. Add your official business email, phone number, registered office address (if desired), privacy policy and legal details.
3. Connect the enquiry form to a real form service or website backend. At present it is a visual/demo form and does not send or store submissions.
4. Do not remove or replace Microsoft 365 DNS records in Namecheap. Website hosting normally requires adding/changing only the website hosting records (often A, AAAA or CNAME) as instructed by the hosting provider. Preserve MX, SPF, DKIM, DMARC and Microsoft verification records.
5. Upload the contents of this folder to your chosen web host's public web directory (often named public_html, www or htdocs).

EASY HOSTING ROUTE
For a beginner, use a managed static website host with a visual dashboard. Create a site, upload the files (or connect a Git repository), then follow that host's instructions to add cloudsavetech.com. The host will provide the exact DNS record values to enter in Namecheap.

No coding is required for ordinary text changes: open index.html in a text editor such as Notepad. For design changes, ask a developer or request help updating these files.

The Google Fonts import requires an internet connection; the site still displays with fallback fonts if it is unavailable.
